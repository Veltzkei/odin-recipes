# odin-recipes
My very first web development project built for The Odin Project curriculum. A clean, multi-page web application showcasing curated recipes, focused on mastering semantic HTML5 structures, proper project directory architecture and Git/GitHub version control workflows.

## ✨ Features
* A structured homepage linking to multiple distinct recipe pages
* Clear use of lists, headings, and images for recipe steps
* Validated semantic HTML tags

## 💻 Technologies Used
* HTML5
* Git & GitHub (SSH authentication)
* WSL2 (Ubuntu Linux environment)

## 📖 Lessons Learned
* Navigating and managing directories via the Linux terminal
* Configuring global Git properties and securely linking machines using SSH keys
* Utilizing the local staging, committing, and pushing workflow to manage remote repositories
